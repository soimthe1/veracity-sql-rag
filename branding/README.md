# Branding

One change rebrands the web UI, page title, login page, API docs and exports.

- `brand.example/` (public): the default brand.
- `brand.local/` (git-ignored): your own brand. When `brand.local/brand.json` exists it wins.

`brand.json` keys: `name`, `name_ar`, `tagline`, `tagline_ar`, `mark` (1-3 letters shown as the logo).
